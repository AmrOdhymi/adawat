# Adawat — Design Preview (Phase 2)

Static, self-contained HTML preview of five interface directions. No build step and no application code.

## Open

Open `index.html` directly in a browser (Edge or Chrome on Windows 10/11).

## Switch

- Use the five buttons in the top bar.
- Press `1`–`5` to switch directions.
- Press `L` to toggle Light/Dark.
- The choice and per-direction mode are saved in `localStorage`.

## Directions

| # | Name | Default mode |
|---|---|---|
| 1 | Fluent Calm | Light |
| 2 | Paper & Ink | Light |
| 3 | Soft Mint | Light |
| 4 | Graphite Pro | Dark |
| 5 | Violet Studio | Dark |

## Surfaces

Wheel, compact Quick Wheel, HUD, Clipboard, Notepad, Settings, Float + context menu, QR result, Screenshot preview, controls, palette, typography, icons, and three future surfaces (file viewer, translation, network monitor).

## Notes

- English UI only.
- System fonts only (Segoe UI Variable, Georgia, Cascadia Mono).
- Light motion, no heavy blur or long animations.
- Design-only: no C# changes, no Build, no app run.
